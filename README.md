# 掘金福利补签兑换助手

在掘金「福利」页按设定次数辅助完成兑换与「确定兑换」确认；仅注入当前页面的脚本，请自行遵守平台规则，矿石兑换不可轻率。

更详细说明：**在掘金 [用户中心 › 福利](https://juejin.cn/user/center/welfare)** 页面，按你设定的次数自动完成「兑换」与弹窗确认（仅限当前页面的辅助）。

## 功能

- **补签卡等福利商品**：在未填写自定义选择器时，脚本会优先在包含「补签卡」的区域附近查找「兑换 / 立即兑换」按钮。
- **确认弹窗**：自动识别含「确定兑换」或常用「确定 / 确认」等按钮；也可通过选择器锁定确认按钮。
- **可配置的循环**：目标次数、每次确认后的间隔与额外停顿（给页面刷新状态）。
- **设置持久化**：使用浏览器 `storage`，下次打开面板可保留上次填写的数值与选择器（需已登录并已开通同步时走 `chrome.storage.sync`，否则行为以浏览器为准）。

## 适用范围

- 匹配站点：`https://juejin.cn/user/center/welfare*`
- 浏览器：建议使用 **Chrome** 或 **Microsoft Edge（Chromium）** 加载本扩展（Manifest V3）。

## 安装（加载「未打包的扩展程序」）

### Google Chrome

1. 克隆或解压本项目到本地目录。
2. 地址栏打开 `chrome://extensions`。
3. 打开右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择本项目根目录（含 `manifest.json` 的文件夹）。

### Microsoft Edge（Chromium）

1. 地址栏打开 `edge://extensions`。
2. 打开左侧 **开发人员模式** 或页面中的开发者选项。
3. **加载解压缩的扩展**，选择本项目根目录。

安装完成后访问掘金福利页即可；扩展图标默认提示：**福利页右下角打开兑换面板**（页面右下角有「签」字按钮展开面板）。

掘金发文可复用：`docs/JUEJIN_ARTICLE_PASTE.md`（含横幅图 Markdown），横幅文件：`docs/article-banner.png`。

## 使用说明（面板字段）

| 字段 | 含义 |
|------|------|
| **目标次数（总点击兑换次数）** | 本轮最多执行多少次「点兑换 → 等确认 → 点确定」流程。 |
| **点「确定」后间隔（毫秒，再发起下一次兑换）** | 每次确认后等待的基底间隔，再走下一次兑换。 |
| **点「确定」后额外停顿（毫秒，给页面刷新状态）** | 与上一项相加，用于前端状态刷新；若过快可略调大。 |
| **兑换按钮 CSS 选择器（可选）** | 页面改版或自动查找不准时填写。留空时自动在「补签卡」等区块附近查找「兑换 / 立即兑换」。 |
| **确认弹窗按钮选择器（可选）** | 若 12 秒内脚本找不到「确定兑换」等按钮，可填弹窗内主按钮的 CSS 选择器。 |

操作流程：填写参数 → **开始**；可随时 **停止**；可 **收起** 面板后用右下角「签」再次展开。

## 常见问题与排查

1. **一直提示找不到「确定兑换」或长时间无确认按钮**  
   - 掘金弹窗结构与类名可能更新，请在开发者工具中对确认按钮「检查」，将合适的 **CSS 选择器**填到「确认弹窗按钮选择器」。  
   - 确认你已真正触发了兑换（网络与登录正常，商品仍可兑换）。

2. **找不到「兑换」按钮或点错元素**  
   - 填写 **兑换按钮 CSS 选择器**，尽量缩小到 welfare 列表里目标商品的那一颗按钮。

3. **修改了源码或配置文件后没有效果**  
   - 前往 `chrome://extensions`（或 Edge 扩展页），对本扩展点击 **刷新/重新加载**，然后 **硬刷新福利页**（Ctrl/Cmd + Shift + R）。

4. **扩展未在任何页面生效**  
   - 仅在 `https://juejin.cn/user/center/welfare` 匹配的 URL 上会注入脚本；请到正确的福利路径。  
   - 确认扩展已启用、未被禁用，且没有在无痕模式下被禁止（若你为无痕会话单独关闭了扩展）。

5. **`storage` / 登录**  
   - 扩展使用 `storage` 权限保存面板配置；需在已允许扩展的条件下使用。
