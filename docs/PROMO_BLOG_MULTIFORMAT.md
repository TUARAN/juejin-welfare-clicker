3. 掘金福利补签兑换助手：可配置次数、间隔与 CSS 选择器

**正文**

最近攒了不少掘金矿石，在「福利」里换补签卡时要反复点「兑换」、再在弹窗里点「确定兑换」，次数一多非常耗时。于是写了一个**仅在福利页注入内容脚本**的 Chrome / Edge（Chromium）扩展：**掘金福利补签兑换助手**，代码已 **MIT 取向的开源**（见仓库 License，以仓库实际文件为准），方便有同样需求的同学自用或二次改造。

### 它能做什么

- 在 `https://juejin.cn/user/center/welfare*` 下显示右下角控制面板，可设置**目标兑换次数**、**确认后的间隔与停顿**，减少人肉连点。
- 自动在「补签卡」相关区域查找「兑换 / 立即兑换」按钮，并在弹窗中识别「确定兑换」或常见「确定 / 确认」类按钮（掘金若改版，可填 **CSS 选择器**精确定位）。
- 支持**随时停止**；参数可借助浏览器 `storage` 记忆（是否跨设备同步取决于浏览器与账号设置）。

### 技术侧一笔带过

- **Manifest V3**，`content_scripts` 只匹配福利路径，无多余主机权限；适合用作前端同学练手「内容脚本 + 少量 DOM 交互」的极简范例。

### 怎么安装

1. 从 GitHub 克隆或下载解压：https://github.com/TUARAN/juejin-welfare-clicker  
2. Chrome 打开 `chrome://extensions`，开启「开发者模式」，**加载已解压的扩展程序**，选项目根目录（含 `manifest.json`）。  
3. Edge 同理：`edge://extensions` → 加载解压缩的扩展。

更细的字段说明、常见问题（找不到按钮、改版后选择器如何填）见仓库 **README.md**。

- **矿石消费与兑换通常不可逆**；请自己核对次数与余额再点「开始」。
